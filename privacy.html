Privacy policy

Last updated 10 November 2026

Hint Me Up Poster is a private publishing tool run by Prateek Vats for the Hint Me Up channel. It uploads Hint Me Up's own puzzle videos to the Hint Me Up YouTube channel and Instagram account. It is not offered to the public, and no one else signs in to it.

What the tool accesses

  • With permission granted through Google sign-in, it uses the YouTube Data API to upload videos and set their title, description and visibility on the Hint Me Up YouTube channel only.
  • It does not read, collect or store data about viewers, subscribers or any other YouTube users.

How information is stored

The sign-in tokens that let the tool upload videos are stored securely in the tool's automation platform (n8n Cloud). They are used only to publish Hint Me Up's own content and are never sold, shared or used for advertising.

YouTube and Google

This tool uses YouTube API Services. By using it, the channel owner also agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be withdrawn at any time from the Google security settings page. Once access is removed, the tool can no longer upload to YouTube, and its stored tokens stop working.
